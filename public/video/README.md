# Hero cloud video

`hero-clouds.mp4` is the drifting cloudscape behind the Home hero's still cloud
plate, referenced by `.amm-hero-cloudvid` in `content/home.html`.

Current file: 1920x546, 6.0s, 30fps, ~375 KB, no audio. Forward-only (no
palindrome), so the clouds drift in one consistent direction and the clip hard
-cuts on loop.

If it is ever re-cut, keep it wide and short, and remember the element is
cropped to a fixed band at the bottom of the stage (`object-fit:cover`,
`object-position:50% 100%`) with a gradient mask fading its top edge into the
sky — only the upper part of the frame reads on screen.

This is placeholder footage pending a final licensed asset.
